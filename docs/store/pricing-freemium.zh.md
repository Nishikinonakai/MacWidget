# 定价与商业模式（建议稿，待机主拍板）

2026-07-25 结论。基于 07-13 调研（MyDockFinder 先例、渠道费率、MoR 现状）+ 今日 MET 许可核实。

## 推荐：Steam ¥25 上下买断（主路径）

- 美区 $4.99，国区按 Steam 建议区间 ¥18–24 取 **¥22**（低于 MyDockFinder 心理线，首发可再 -10% 折扣）
- 理由：
  1. 同市场付费先例成立（MyDockFinder $4.99，估 50–100 万 owners，73% 好评）
  2. Steam 代扣税、退款、分发、更新、防盗版全包——**零后端、零账号系统**（符合既定原则）
  3. 打赏模式在国内桌面工具的转化惯例 <1%，且爱发电/面包多有过监管性域名事故、不代扣税
  4. **API 成本矛盾已消解**：天气默认源 MET Norway = CC-BY 商用免费，无按用户量增长的边际成本
     → 不需要订阅、不需要付费代理后端来养 API

## 明确不做（v1）

- **付费代理后端（API 转发）**：要养服务器 + 账号体系（违背"不做账号"原则）+ Paddle 收款
  （5%+$0.50，大陆个人唯一主流 MoR）+ 滥用防控 + 可用性责任——全部为了解决 MET 已经免费
  解决的问题。**留触发条件**：将来要上真收费数据（气象雷达图/AQI/多日精细预报）再评估。
- 限时试用：Steam 有退款兜底，无需试用机制。

## 保留 / 可选

- **BYO API key**：架构已留槽（组件 cfg 的 {source, key}），将来加"和风天气"等源=用户自备 key
  本地直连，零成本满足数据偏好党。非卖点，是口碑项。
- **免费引流**：MacDesk 保持免费（现状），是 MacWidget 的天然广告位与联动护城河；
  若想试水打赏，挂在 MacDesk 的 README/关于页（爱发电），与 MacWidget 售卖互不干扰。
- **官网直销副渠道**（远期）：Ed25519 激活码 + 机器绑定（Keygen CE 自托管免费层），
  等 Steam 渠道跑顺再说。
- **MS Store 副渠道**：个人注册免费（2025-09 起），MSIX 85/15；国区支持支付宝——
  等主渠道发布后顺手上，作为"正版免安装器"入口。

## Steam 上的"免费体验"形态

Steam 单 App 内做不了 freemium。两个可选形态：
1. **只发付费本体**（推荐首发）：退款政策就是试用
2. 后续加 **Demo App**：锁 3 个基础组件（时钟/日历/系统监视），一键升级正式版
