# 公开产品名改名技术计划

前提：机主从 [命名 shortlist](naming-shortlist.zh.md) 或其他候选中确定公开产品名，并完成计划销售地区的
商标与商店名核验。本计划把“公开品牌”与现有的内部技术标识分开，目标是在不丢失用户布局、不制造第二实例、
不断开 MacDesk 联动的前提下完成首个品牌化版本。

## 结论：先做公开品牌改名，不立刻改技术标识

首个品牌化版本应更新用户可见名称、商店文案、视觉资产和安装器显示名；**暂时保持**以下内部兼容标识：

| 标识 | 当前值 | 首个品牌化版本的处理 | 原因 |
| --- | --- | --- | --- |
| Inno Setup `AppId` | `{A2253620-97A8-4AFB-8EF9-97CC6340A2C2}` | 保持不变 | 这是旧安装升级、卸载与安装位置识别的锚点；改掉会被 Windows 当作第二个产品。 |
| 安装目录与可执行文件 | `Programs\MacWidget\MacWidget.exe` | 保持不变 | 保证已安装版本原地升级；以后若迁移路径，必须有单独迁移与回滚测试。 |
| 用户数据目录 | `%LOCALAPPDATA%\MacWidget` | 保持不变 | 内含 `settings.json`、`layout.json`、WebView2 用户数据与日志；改目录会使用户看似“丢组件”。 |
| 单实例与控制事件 | `MacWidget.SingleInstance.v1`、`MacWidget.Command.*.v1` | 保持不变 | 既有安装器升级、`--restart`、`--quit` 和 MacDesk 打开组件库都依赖它们。 |
| MacDesk 避让管道 | `MacDesk.WidgetAvoid.v1` | 保持不变 | 协议名与产品营销名无关，改动会让已部署的 MacDesk 联动失效。 |
| 自启动注册表值 | `HKCU\...\Run\MacWidget` | 保持不变 | 技术键名不可见；保留避免升级后双自启或旧项残留。 |

因此，公开名称与内部 `MacWidget` 允许暂时不同。Windows 的开始菜单、安装器、托盘标题、商店页和截图都呈现
新名称；用户不会看到路径、事件或注册表值。这个分层比一次性“全局重命名”安全得多。

## 第一阶段：首个品牌化版本（必须完成）

1. 在项目中集中定义公开显示名，替换安装器 `AppName`、`AppVerName`、开始菜单快捷方式、托盘/面板窗口标题、
   用户可见错误文案和 README；内部路径、EXE 名与协议常量保持不变。
2. 将 MacDesk 设置页和右键菜单中的显示文字切换为公开名，但其探测逻辑继续识别 `MacWidget.exe` 和既有 App Paths。
3. 用选定名称制作标题字标、Main/Header/Small/Vertical capsule、Library Logo 与中英文 Store 文案；更新截图中
   任何显示旧名的部分。
4. 用真实的已安装旧版执行升级回归：安装器能退出旧实例、原地升级、恢复原有布局/设置、保持单实例，并能从
   MacDesk 打开组件库及发送图标避让矩形。
5. 验收时保留现有 `smoke-installed.ps1 -ExerciseRestart -RequireMacDeskLink`，并补充检查新的公开显示名。

## 第二阶段：可选的技术重命名（单独版本，不与第一阶段捆绑）

只有在确实需要 EXE、数据目录或协议也使用公开名时才做。该版本需要至少一轮兼容桥接：

1. 新 EXE/目录保留旧 EXE、App Paths 和自启动项的读取/退出兼容；安装器同时处理旧、新进程名。
2. 首次启动时以原子、可回退方式迁移 `%LOCALAPPDATA%\MacWidget`，包括布局、设置和 WebView2 数据；迁移失败
   时继续使用旧目录，绝不能创建空白新布局覆盖旧数据。
3. 单实例、编辑事件与 MacDesk 管道需同时监听/尝试旧值和新值至少一个发布周期；MacDesk 发现逻辑也须接受两套
   EXE/App Paths。
4. 在旧安装升级、卸载后重装、回滚、MacDesk 新旧组合和多显示器布局场景做完整真机回归，再移除旧别名。

## 禁止事项

- 不要为改名生成新的 Inno `AppId`；那会绕开现有安装而产生并存副本。
- 不要在未迁移用户数据前更改 `DataDir`。
- 不要只改 MacDesk 的菜单文案而忘记事件/路径兼容；“Edit Widgets…”会表现为无反应或打开第二实例。
- 不要把商店名、EXE 名、管道名强行在同一版本统一；它们的风险和迁移节奏不同。
