# MacWidget 公开产品名 shortlist

状态：2026-07-26 的**公开网页与主流应用商店初筛**。这份文件用于缩小机主的命名选择，**不是**商标检索、
域名注册或法律意见；选定一个名称后，仍须在计划销售地区完成正式商标与商店名可用性核验，再改动公开
文案、安装器和应用标识。

## 建议先选其一

| 候选名 | 含义与产品贴合 | 初筛结论 | 取舍 |
| --- | --- | --- | --- |
| **Modulune** | module + lune；强调可组合的小组件与柔和夜间桌面感 | 未找到同名 Steam、Microsoft Store 或 App Store 产品 | **首选**：是造词，区分度高；首次看到时需要一点读音教育。 |
| **Paneora** | pane + aura；表达浮在桌面的玻璃信息卡片 | 未找到同名主流软件产品；`Panestra` 等近似词已有非软件地名，故不选近似拼写 | **次选**：视觉语言很贴合；读音不如 Modulune 直观。 |
| **GlimmerDesk** | 桌面上的微光信息层 | 未找到同名主流软件产品 | **备选**：意思直接、易理解；`Desk` 类名称较拥挤，独占性弱于前两者。 |

推荐的商店呈现方式：只用英文主名称（例如 `Modulune`），副标题用功能描述而不是塞入产品名，例如
“Desktop widgets for Windows”。这样后续若改变定位，不必重做主品牌。

## 已排除的名字

- **MacWidget**：已有同名同类 macOS 应用 [MacWidget - Desktop Widgets](https://apps.apple.com/us/app/macwidget-desktop-widgets/id6747938136?mt=12)。
- **Deskora**：已有同名 Windows 桌面整理产品 [Deskora](https://www.deskora.de/en/)。
- **DeskLoom**：已有同名 Windows desktop widget manager [DeskLoom](https://strictseal.com/product/deskloom)。
- **PanelNest**、**LumaPanel**、**Lumora**、**Nestly**、**Auraloom**：分别已有家具、照明或活跃软件/应用使用，
  不适合作为这一品类的公开名称。

## 选定后必须做的事

1. 在目标市场完成商标、Steam、Microsoft Store 和域名可用性检索；必要时咨询商标代理或律师。
2. 确认用 `Modulune`、`Paneora` 或 `GlimmerDesk` 中的哪一个作为公开产品名后，再锁定标题字标与 capsule。
3. 统一替换公开 Store 文案、安装器显示名、应用元数据、截图与视觉资产；内部仓库名/进程名可另行评估，
   不必和公开名在同一提交中强行捆绑。
